# 模块、角色与数据边界

本文解释当前实现中可开关的业务模块、不可关闭的核心能力，以及前后台授权关系。使用步骤见 [使用与运营手册](USER_GUIDE.md)。模块开关不等同于授权：一个模块已开启，不代表任何登录用户都能查看私有数据或执行管理操作。

## 1. 业务模块目录

共享目录的唯一实现入口是 [`server/src/modules/catalog.js`](../server/src/modules/catalog.js)。服务端、后台导航与 uni-app 使用相同模块键。表中列出能力范围，不代表新环境已具备数据、服务密钥或第三方业务授权。

| 分组 | 模块 / ID | 前台能力 | 后台能力与前提 |
| --- | --- | --- | --- |
| 内容与互动 | 湖财圈 `community` | 校园墙、话题、帖子、评论、轮播焦点 | 内容发布/下架与举报处理；正式实名发言直接发布仍受敏感词保护 |
| 内容与互动 | 对话 `chat` | 私聊、自建群、固定学籍群、文件、图片、表情包 | 全局管理员对话管控、群主指定、表情包管理；持久化存储与上传配额须配置 |
| 内容与互动 | 公告与消息运营 `announcements` | 已发布且符合受众/时段的公告与组织通知 | 草稿、发布、下架、受众、时段及置顶维护；本人办理通知不是此开关的删除对象 |
| 内容与互动 | 官网资讯同步 `official-content` | 资讯列表、详情、收藏 | 允许来源的官网内容同步；网络、解析规则及来源发布状态影响可用性 |
| 校友连接 | 校友组织 `organizations` | 分类、自动匹配、主页、成员、相册、留言 | 组织资料、记录级管理授权、成员/活动/事项运营 |
| 校友连接 | 校友名录 `directory` | 符合公开条件的校友资料 | 维护公开名录；不等同于后台全部平台账号 |
| 校友连接 | 同城地图 `maps` | 本地街道图、学校标注、公开名录城市聚合 | 全局管理员维护 PMTiles 底图与 GeoJSON 图层；内置范围为长沙及周边，不是全国街道库 |
| 校园服务 | 活动 `activities` | 活动列表、详情、报名 | 活动维护、发布、报名处理；归属组织活动同时受组织模块影响 |
| 校园服务 | 返校预约 `campus-visits` | 提交日期/事由并查询进度 | 返校申请办理；不是动态核验码本身 |
| 校园服务 | 返校身份核验 `gate` | 身份卡动态码、授权人员扫码确认 | 门岗、负责人、保安授权及核验记录；不自动包含闸机硬件接入 |
| 校园服务 | 服务办理 `services` | 服务目录及申请 | 服务项目和申请办理；全部服务导航属于基础入口，不随此模块一并消失 |
| 校园服务 | 校历 `calendar` | 学期、教学、考试、假期等日程 | 校历事项、受众与优先级维护 |
| 校园服务 | 意见反馈 `feedback` | 提交本人反馈 | 反馈分类、处理和回复 |
| 资源与发展 | 校友企业 `enterprises` | 企业名录、企业认证、本人企业工作台 | 主体审核与申请人绑定；企业查询为另行配置的企查查授权接口 |
| 资源与发展 | 岗位招聘 `jobs` | 招聘、本人企业岗位编辑、申请/收藏 | 岗位审核与发布；企业主发帖还受企业认证和绑定条件限制 |
| 资源与发展 | 合作广场 `collaboration` | 资源需求与供给浏览/提交 | 合作信息维护、审核及发布 |
| 资源与发展 | 校友导师 `mentors` | 导师列表、本人导师资料及申请 | 导师记录和本人账号绑定；导师资格由业务管理确认 |
| 资源与发展 | 校友课堂 `academy` | 已发布课堂和学习内容 | 课程内容维护；不意味着已集成独立直播或外部教学平台 |
| 资源与发展 | 校友权益 `benefits` | 已发布权益与领取 | 权益项目和领取记录管理；兑现需遵守项目实际说明 |
| 公益与回馈 | 志愿服务 `volunteers` | 志愿项目及报名 | 项目维护与报名办理 |
| 公益与回馈 | 回馈母校 `giving` | 公益项目、意向提交及本人证书 | 项目、证书模板、真实到账确认及签发；没有默认在线收款通道 |

### 1.1 开关行为

- 全局管理员在模块管理中保存开关，服务端使用版本校验防止覆盖他人更新。
- 前台导航、后台导航、汇总数据及相关接口按模块状态过滤/限制。仅隐藏按钮并不是安全边界，真正操作仍由服务端校验。
- 关闭模块不会删除存量记录、上传文件或成员数据；重新开启后仍需满足内容发布条件和用户权限。
- 跨模块记录会检查相关模块，例如某组织的活动还依赖组织模块。关闭一个模块可能减少其他页面的相关统计或入口。
- 页面会刷新配置；短暂网络失败可能保留上次确认的界面状态。不能据此绕开服务端的关闭状态。

### 1.2 不可关闭的核心能力

| 核心能力 | 保留原因 |
| --- | --- |
| 账号与身份 `accounts` | 登录、实名、个人资料、密码与账号管理是访问控制基础 |
| 系统与审计 `audit` | 保留日志和模块恢复入口，避免管理员将自己锁出 |
| 基础能力 `infrastructure` | 首页/服务导航、行政区域、敏感词和本人通知承担全局依赖 |

校内人员档案归属于账号管理的受限能力，不是一个公开校友页面。关闭校友名录不会把账号管理一起关闭。

## 2. 角色与权限矩阵

| 主体 | 可执行的典型动作 | 不能据此获得的能力 |
| --- | --- | --- |
| 访客 | 浏览允许公开的内容 | 私聊、查看本人业务、申请材料或后台 |
| 登录普通人员 | 查看本人资料及符合条件的功能；完成首次改密/实名 | 仅靠登录不能获得实名发布与管理权 |
| 正式实名用户 | 符合业务规则的发帖、评论、报名、建群、企业申请和相册操作 | 其他人的私有资料、企业/组织任意管理权 |
| 企业认证申请人/企业主 | 在认证和绑定有效时维护本人企业及其招聘 | 其他企业资料或跳过后台审核 |
| 组织管理人员 | 被授权组织的对应查看、修改、审核、成员管理 | 其他组织或账号全局管理 |
| 群主/群管理员 | 按群类型及权限管理群 | 固定群自由增删学籍成员、任意读取他人私聊 |
| 核验人员/保卫负责人 | 扫码确认；负责人按范围管理人员和站点 | 仅有门岗权限不能读取全部账号/聊天/内部档案 |
| 板块/记录管理员 | 在授权资源和记录范围内执行所授操作 | 系统配置、全局账号、全量人员档案或对话审计 |
| 全局管理员 | 账号/配置/授权、受控内部资料及管理操作 | 绕过密码状态、记录版本、身份唯一性或数据保留规则 |

资源授权操作键为 `read`（查看）、`create`（新增）、`update`（修改）、`moderate`（审核/发布处理）、`manage_members`（成员/管理授权）。记录级授权不能因此创建任意同类记录；具体 UI 能力还取决于记录状态。授权过期或父授权撤回会影响下级授权。

敏感的全局能力包括账号导入、人工直接核验、密码重置、校友编号下发、校内人员档案、模块配置、学校认证配置、区域/地图配置、企业查询密钥配置、敏感词、聊天监督和表情包管理。运营中应优先按资源/记录授权，不要把每位值班人员都设为全局管理员。

## 3. 需要区分的数据和流程

### 3.1 身份资料、个人资料与内部档案

1. **身份资料**：学校认证或授权人工核验的姓名、学院、专业、班级、学工号、年份等；来源可追溯，普通用户不能自行改写核验字段。
2. **个人资料**：本人补充的联系信息、城市、简介；不自动变成公开名录。
3. **内部档案**：校内关系维护的标签、教育/工作经历、备注、供需、合作和跟进记录；只对全局管理员提供对应接口，不修改前台身份或业务审批。

内部档案“资料概览”按现有记录计算，不是外部 AI 推断。公开仓库不包含人员数据，部署者应另行建立适当的数据权限、告知、保存与删除制度。

### 3.2 公开发言和业务申请

实名发帖/评论/组织留言可以直接发布，但仍须通过敏感词和权限检查，后台可下架。企业认证、活动报名、服务申请、人工身份材料等不是“发言”，仍按对应审核流程处理。

匿名发言仍有关联作者；公开呈现的随机头像/昵称不是后台不可识别保证。个人聊天也不是端到端加密消息系统，后台监督是独立的授权路径。

### 3.3 自动组织和固定聊天群

学院、专业、年级、班级的自动关联只依据符合身份条件的明确字段；城市、行业和兴趣组织还依赖实际已有的明确数据。资料缺失不猜测补全。

组织中退出状态可以被记住；固定聊天群不可自行退出，随学籍资格变更重新匹配。后台指定群主后，群主才按群规则管理管理员。两套成员关系不是同一张权限表。

### 3.4 捐赠意向、到账与内部备注

意向金额是用户填写信息；正式到账需授权人员核对学校财务/回执，证书签发使用独立确认字段和模板快照。内部档案中的捐赠联系记录不记为到账，也不能生成证书。

### 3.5 地图位置与审计地点

本地地图的人员分布目前是公开名录的城市聚合，学校中心为主校区标记，不是门岗或个人坐标。审计 IP 归属地来自网络信息与 IP 库，不是 GPS。VPN、代理和运营商出口可能导致不准确，内网没有可信的城市结论时不应补造地点。

## 4. 配置与外部依赖清单

| 能力 | 部署方需要准备 | 未完成时的边界 |
| --- | --- | --- |
| 学校实名认证 | 学校批准的 CAS/OIDC 参数、字段映射、HTTPS 回调、相关端安全回跳 | 保持未启用或拒绝无绑定注册；不伪造认证成功 |
| 人工身份复核 | 授权复核人员、材料访问控制、明确依据、身份冲突处理 | 不能仅点击状态来覆盖任意账号 |
| 企业登记查询 | 已获得授权的企查查密钥与额度，后台启用 | 手动填表仍可用；查询成功不代替主体审核 |
| 官网同步 | 合法来源、可用网络、解析与发布检查 | 无可用内容时按实际状态提示，不编造资讯 |
| 地区选择 | 正确父子层级和启用状态的行政区域库 | 导入行政区不能生成地图道路几何数据 |
| 本地街道地图 | 当前已发布底图、坐标系/范围、资源服务、WebGL、地图来源许可 | 内置只覆盖长沙周边；其他地区需上传和验证 |
| 文件/图片/材料 | 私有持久存储、配额、分片与代理配置、目标端能力 | 上限不等于任意设备一定可传；拒绝非法格式或不足空间 |
| 返校扫码 | 正常账号、站点、负责人/保安授权、相机权限 | 二维码预览不是放行，硬件闸机需独立接入 |
| 公益证书 | 有权签发人员、真实到账/回执、有效模板 | 意向不自动收款、不自动签发 |
| IP 审计 | 可信代理 CIDR、真实请求来源、合适的 IP 地域库 | 不信任所有 `X-Forwarded-For` 来源，不承诺精确地址 |
| 正式账号安全 | HTTPS、独立密钥、首次改密、授权及备份恢复 | 仓库不提供生产账号或通用密码 |
