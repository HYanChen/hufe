## 公开内容边界

- 公开版本使用虚构测试人员资料，不附带真实人员业务快照。
- 不提交运行环境文件、生产密码、密钥、用户上传材料、聊天附件或数据库备份。
- 公开文档移除内部数据库标识、备份位置和实际业务数量。
- 发布包采用独立全文件清单和 SHA256 校验，不能使用旧交付 ZIP 的 SHA 校验新包。
- 本次主要更新文档及测试样例。公开运行归档 `20260916-public-sanitized` 保留基线 `20260915T175805Z-8992df7e` 的业务程序、网页成品及 Linux 依赖，仅将两个历史迁移工具的专站标识改为示例并重建清单；使用独立 SHA。小程序/App 编译探针不放入运行归档。

## 尚需部署方完成的验收

1. 目标服务器 Node/MySQL、磁盘容量、HTTPS、代理与私有文件目录检查。
2. 真实 MySQL 隔离环境测试、数据迁移、备份恢复演练；禁止对生产库运行重置测试。
3. 正式学校 SSO、企业信息接口及其他外部服务的配置与联调。
4. 微信/支付宝开发者工具、真机、系统权限和平台审核；Android/iOS 签名、原生插件及商店流程。
5. 真实 5 GiB 文件传输，以及目标网络、限流、断点恢复和容量监控专项验收。
6. 上线后的账号权限、会话互斥、证书、通知、地图与业务流程抽查。
